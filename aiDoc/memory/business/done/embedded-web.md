# Go 内嵌前端发行模式

- 提出日期：2026-11-27
- 当前状态：`done`
- 需求类型：构建与部署

## 用户原始意图摘要

先分析将前端产物 embed 到 Go 进程的可行性，随后要求开始实施。

## 已确认约束

- 采用可选的 `embedweb` 发行模式，保留普通后端构建和 Vite 开发方式。
- 保留同源 `/api` 约定，在 Go HTTP 入口剥离前缀，不改业务 API 和鉴权。
- 仅内嵌前端产物；配置、上传、数据库和模板依赖保持外置。

## 影响范围与交付

- `server/internal/webui/`：嵌入、静态资源和 API 分流，以及两种构建模式的测试。
- `server/core/`：接入 HTTP handler。
- `Makefile`、`deploy/docker/Dockerfile.embed*`、CI：构建与验证链路。
- `aiDoc/frontend-backend/boundary.md`、`aiDoc/relations/embedded-web.md`：契约与使用说明。

## 限制

- 内嵌模式要求空 `system.router-prefix`，不支持任意页面子路径。
- 不包含预压缩、旧版本 chunk 保留或整套应用的完全单文件化。
